# Runbook: отправка заказов Ozon Доставкой

Ozon Доставка подключена без API создания отправлений: сайт считает цену и сохраняет выбранный пункт, а **отправление склад оформляет вручную в кабинете Ozon**. Номер отправления вносится в карточку заказа — клиент видит трек в ЛК и получает письмо.

```
Оплачен → В сборку → Собрать и упаковать → Отправление в кабинете Ozon → Этикетка → Сдать в Ozon → Трек в заказ → «Заказ отправлен» → Письмо с треком
```

## Кто и где

| Роль | Что делает | Где |
|------|-----------|-----|
| Склад | Сборка, упаковка, отправление в Ozon, трек | Админка → Заказы → заказ → «Чеклист отправки Ozon» |
| Супер-админ | Подключение Ozon, проверка API | Админка → Настройки → Службы доставки |
| Поддержка | Вопросы клиента по доставке | Чат заказа |

## Перед сменой (1 минута)

1. **Настройки → Службы доставки**: статус Ozon «Подключено». Если нет — см. «Ozon отключён» ниже.
2. **Заказы** → чип **«Ozon без трека»**: оплаченные заказы Ozon, по которым ещё нет отправления. Это очередь на смену.
3. **Заказы** → чип **«Ozon без факта стоимости»**: отправленные, по которым списание уже видно в кабинете Ozon, — внести суммы (шаг 10).
4. Этикеточный принтер, коробки, плёнка, весы, рулетка — на месте.

В строке списка те же признаки видны бейджами «Ozon: нет трека» / «Ozon: внести стоимость».

## Заказ: шаг за шагом

Откройте заказ. В блоке «Отправка» — плашка **«Автосоздание отправления Ozon недоступно»** с тремя шагами и ссылкой на кабинет; кнопка **«Данные для формы и чеклист»** открывает все поля для формы Ozon с кнопками «Копировать» и чеклист. Пункты «авто» отмечаются сами по статусу заказа. Пункт выдачи в блоке «Доставка» помечен **«Ozon · выбран покупателем»** — это ID Ozon, не код ПВЗ СДЭК; кнопки СДЭК в заказах Ozon скрыты.

1. **Оплата получена.** Статус «Оплачен». Заказы «Ожидает оплаты» не собираем.
2. **В сборку.** Кнопка «В сборку» — клиент видит, что заказ собирается.
3. **Собрать.** Сверить артикулы, оттенки, количество с составом заказа. Проверить сроки годности и целостность. Подарок благодарности (строка с ценой 0) — положить в посылку.
4. **Упаковать.** Стекло — в пузырчатую плёнку, жидкости — в зип-пакет, пустоты заполнить. Взвесить (г) и измерить Д×Ш×В (см) — понадобятся в форме Ozon.
5. **Создать отправление в кабинете Ozon** (ссылка «Открыть кабинет Ozon» в окне чеклиста):
   | Поле в Ozon | Откуда |
   |-------------|--------|
   | Номер заказа продавца | «Номер заказа продавца» (номер заказа на сайте) |
   | Получатель, телефон | «Получатель», «Телефон получателя» |
   | Пункт выдачи | **«ID пункта Ozon»** — искать по ID, не по адресу |
   | Адрес (курьер) | «Город», «Адрес доставки», «Индекс» |
   | Объявленная ценность | «Объявленная ценность» — сумма оплаченных товаров без доставки |
   | Вес, габариты | По факту из шага 4 |
   | Оплата при получении | **Нет** — заказ оплачен на сайте |
6. **Этикетка.** Распечатать, наклеить на самую большую грань. Номер заказа — маркером на коробке.
7. **Передать в Ozon.** Сдать в пункт приёма или курьеру Ozon, сохранить акт/подтверждение.
8. **Трек в заказ.** Номер отправления из кабинета Ozon → поле «Трек» → **«Заказ отправлен»**. Без трека кнопка неактивна.
9. **Письмо клиенту.** «Отправить трек-номер» — письмо на email заказа.
10. **Стоимость из кабинета.** Когда Ozon покажет списание за отправление, внесите сумму в «Отправления» → «Стоимость у Ozon, ₽» — **по каждому отправленному заказу Ozon, без исключений**. Сумма — фактическое списание за доставку (без возвратов и штрафов). Рядом сохранится оценка по нашей сетке. Заказ уходит из чипа «Ozon без факта стоимости». Ошиблись — «Изменить».

Целевой срок (поправьте под график склада и приёма Ozon): заказ, оплаченный до 14:00 рабочего дня, передан в Ozon в тот же день; остальные — на следующий рабочий день.

## Ежемесячно: сверка тарифа (супер-админ, 1-е рабочее число)

1. **Заказы → «Ozon без факта стоимости»** — должно быть 0 за прошлый месяц. Если нет — дозаполнить со складом по кабинету Ozon: без факта отправление в сверку не попадает.
2. **Настройки → Службы доставки → «Тарифная сетка Ozon»**, период 30 дней (при малом объёме — 90):
   - «Смещение (факт − сетка)» в пределах ±10% и нет подсвеченных строк — сетка в норме, ничего не делать;
   - подсвечена ступень (≥ 5 отправлений, отклонение ≥ 10%) или множитель курьера — см. п. 3.
3. Пересмотр: скопировать предложенные строки `OZON_TARIFF_*` из карточки → проверить здравый смысл (нет скачков из-за 1–2 нетипичных посылок) → добавить в `/opt/miraflores/backend/.env` на VPS → `systemctl restart miraflores-api`. В `OZON_TARIFF_VERSION` — месяц, например `2026-10-reconciled`.
4. Записать итог в задачу/чат команды: период, число отправлений, смещение, что поменяли. В ближайший релиз разработчики переносят сетку в `DEFAULT_OZON_TARIFF` и убирают override из env.
5. Заодно — карточка «Габариты каталога»: новые товары без веса и размеров искажают оценку. «Применить предложения» для строк с предложением; остальные (пробники, наборы, товары без объёма) — «Править» в строке: вес с весов в граммах, размеры упаковки в мм.

Что значит смещение: **плюс** — Ozon берёт больше, чем платит покупатель (теряем на доставке); **минус** — покупатель переплачивает (страдает конверсия).

## Нештатные ситуации

| Ситуация | Что делать |
|----------|-----------|
| В чеклисте «Нет ID пункта Ozon» | Не создавать отправление наугад. Написать клиенту в чат заказа, уточнить пункт; «Изменить адрес» в заказе → выбрать пункт Ozon. |
| Пункт закрыт / не принимает | То же: согласовать с клиентом другой пункт, изменить адрес в заказе, затем оформлять. |
| Нет товара / брак при сборке | Не отправлять частично без согласия. Чат с клиентом → «Изменить состав» (доплата/возврат разницы считается автоматически) или отмена с возвратом. |
| Посылка не влезает в лимиты Ozon | Согласовать с клиентом СДЭК: «Изменить адрес» → СДЭК; при другой цене — «Стоимость доставки» в заказе. |
| Ошиблись в треке | Ввести правильный трек и снова «Отправить трек-номер» — клиенту уйдёт письмо с верным номером. |
| Клиент не забрал / возврат | Отслеживать в кабинете Ozon. После возврата на склад — приёмка, затем возврат денег в заказе («Возврат»). |
| **Ozon отключён** (статус не «Подключено») | Витрина сама скрывает Ozon и просит выбрать СДЭК; новые заказы Ozon не создаются. Уже оплаченные — оформлять как обычно: кабинет Ozon работает независимо от подключения к сайту. Супер-админ: «Подключить Ozon» → войти в Ozon → «Проверить API». |
| Пункты Ozon не грузятся на сайте | Клиент видит «Не удалось загрузить пункты выдачи Ozon» с кнопкой «Повторить»; оформление через СДЭК доступно. Если дольше часа — «Проверить API» в настройках, при ошибке — переподключить. |

## Для разработчиков

- Статус подключения для витрины: `GET /api/v1/delivery/ozon/availability` → `{ available, message }`. `POST /delivery/ozon/pickup-points` всегда отвечает 200 с `available` / `degraded`, без 5xx.
- Квота `OZON` отклоняется (400), если Ozon не подключён.
- Чеклист: `Admin/lib/shipping/ozonFulfillment.ts` (поля и шаги), `Admin/app/(admin)/admin/orders/OzonFulfillmentChecklist.tsx`. Ручные отметки — на сервере (`OrderChecklistMark`, `PUT /orders/admin/:id/checklist`), общие для всех смен и устройств, с автором и временем. Новый ручной шаг нужно добавить и в `OZON_CHECKLIST_STEPS`, и в `ORDER_CHECKLIST_MANUAL_STEPS` (`backend/src/orders/order-checklist.ts`).
- Ссылка на кабинет: `NEXT_PUBLIC_OZON_CABINET_URL` (по умолчанию `https://seller.ozon.ru/`).
- Архитектура, env, тариф, мониторинг — [docs/ozon-delivery.md](../ozon-delivery.md).
